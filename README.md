# Shipping Rate Calculator

## Overview

This project was developed as an individual assignment for the Software Testing course.

The objective is to implement a Shipping Rate Calculator and verify its correctness using software testing techniques.

---

## Features

- Shipping rate calculation
- Loyalty discount
- Destination zone handling
- Exception handling
- Unit testing with JUnit

---

## Testing Techniques

This project applies:

- Equivalence Partitioning
- Decision Table Testing
- Boundary Value Analysis
- JUnit Test Cases

---

## Project Structure

src/main
- ShippingRateService.java
- Shipment.java
- DestinationZone.java

src/test
- ShippingRateServiceTest.java

---

- Java
